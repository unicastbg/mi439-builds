# Mi439 Builds

Release assets for unofficial LineageOS builds for Xiaomi Mi439 variants.

Use this repository's GitHub Releases to host signed ROM zips. The OTA metadata
repository points the LineageOS Updater at those release asset URLs.

Expected asset naming example:

```text
lineage-23.2-YYYYMMDD-UNOFFICIAL-Mi439-signed.zip
```

Do not commit ROM zips directly to git. Upload them as release assets instead.
